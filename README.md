# SNMP-Based Server Room Monitoring System

## Overview
A Python-based academic project for monitoring server room parameters using the Simple Network Management Protocol (SNMP).

## Features
- SNMP manager and agent architecture
- Custom MIB objects for server room monitoring
- SNMP GET, GET-NEXT, GET-BULK and SET operations
- Tkinter-based manager interface
- ASN.1 and BER encoding and decoding
- Test file for checking project functionality

## Technologies
Python, SNMP, ASN.1, BER, MIB, Tkinter

## Running Tests
Run the following command in Terminal:

    python3 test_snmp.py

## Note
This is an academic project. Test the components in your environment before relying on the results.
